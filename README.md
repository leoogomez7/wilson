# 🌐 Wilson Arquitectura
**Wilson Arquitectura es una plataforma web oficial y portafolio interactivo de alto impacto diseñado exclusivamente para un estudio de arquitectura. El proyecto combina una estética visual sofisticada, minimalista y limpia con una experiencia de usuario (UX) sumamente fluida, pensada para exhibir proyectos residenciales, remodelaciones y direcciones de obra con el objetivo de convertir visitas en contrataciones directas.

🌐 **Sitio Web Oficial:** [wilsonarquitectura.com.ar](https://wilsonarquitectura.com.ar/)

# 💡 ¿No eres programador? Te lo explicamos en simple
Si no tienes experiencia en tecnología o desarrollo web, aquí te explicamos fácilmente de qué trata esta plataforma:

**¿De qué se trata la página?:** Es la sede digital y el portafolio oficial para un estudio de arquitectura. Funciona como una galería interactiva donde los clientes pueden explorar casas construidas, renders 3D en alta resolución y conocer los detalles de cada obra.
**¿Para qué sirve?:** Permite mostrar el trabajo del estudio de forma elegante y profesional, transmitir confianza a futuros clientes y facilitar que contacten directamente para solicitar presupuestos o iniciar nuevos proyectos de construcción.
**¿Por qué es rápida e interactiva?:** Utiliza tecnología web avanzada que permite cargar imágenes de alta calidad al instante, navegar entre categorías y ver planos o renders sin demoras ni cargas molestas.
**¿Cómo se ve en celulares?:** Cuenta con un diseño adaptativo (responsive), garantizando que las fotos de las obras y los botones de contacto se vean y funcionen perfectamente desde cualquier smartphone, tablet o computadora.

# 🚀 ¿Qué es Wilson?
Esta plataforma actúa como el motor de imagen de marca y portafolio digital del estudio. Está optimizada técnicamente para garantizar una presentación impecable mediante las siguientes características:

**Catálogo de Obras al Detalle:** Desglose visual completo de proyectos residenciales, superficies en metros cuadrados, renders e imágenes finales en alta resolución.
**Arquitectura Enfocada en Conversión:** Puntos de contacto estratégicamente ubicados para agilizar la consulta de presupuestos, asesorías o reuniones.
**Rendimiento UI Excepcional:** Carga instantánea de recursos multimedia y transiciones fluidas gracias a una arquitectura optimizada.
**Diseño Responsive & Mobile-First:** Adaptabilidad total a cualquier tamaño de pantalla para asegurar una visualización impecable desde dispositivos móviles.
**Despliegue Global:** Alojamiento en redes de alta velocidad que garantizan baja latencia y alta disponibilidad.

# 🛠️ Stack Tecnológico
El proyecto está desarrollado con tecnologías web modernas y de tipado seguro para garantizar escalabilidad, rendimiento y cero errores.

### Frontend & UI
**React.js & TypeScript:** Lógica de cliente robusta, escalable y con tipado estático seguro.
**Vite.js:** Servidor de desarrollo instantáneo y empaquetado ultra optimizado para producción.
**Tailwind CSS & Componentes UI:** Estilos ágiles, diseño adaptativo y componentes modernos para una estética limpia y consistente.

### Entorno de Ejecución & Dependencias
**Bun / Node.js:** Gestor de paquetes eficiente y ejecutor de entornos JavaScript de alto rendimiento.

### Calidad de Código
**ESLint & Prettier:** Reglas de validación estática y formateo automático para mantener un código limpio y legible.

### Infraestructura & Cloud
**Vercel Edge Network:** Alojamiento perimetral en la nube con compresión automática y entrega global de alta velocidad.

# ⚙️ Requisitos Previos
Se recomienda contar con Node.js o Bun instalado en tu entorno local para la gestión de dependencias y ejecución de scripts.

🚀 Instalación y Uso Local
Clonar el repositorio:

Bash
git clone https://github.com/leoogomez7/wilson.git
cd wilson
Instalar dependencias:

´´´Bash
bun install
# o bien
npm install
Ejecutar el servidor local de desarrollo:

Bash
bun run dev
# o bien
npm run dev
Compilar el proyecto para producción:

Bash
bun run build
# o bien
npm run build
